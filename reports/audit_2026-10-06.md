# Project audit before the final push (2026-10-06)

Method: static checks on all 148 Python files, a secret scan of the 413 files git would push, dependency and workflow review, a read-only review of Google Cloud (IAM, Cloud Run, bucket, Pub/Sub, secrets) and of the live database, black-box checks of the live URL, and the full unit suite (1,494 passed). Nothing in the cloud or the databases was changed by the audit.

## Fixed during the audit
1. The planner and the answer-writer prompts still said "12 research papers ... plus one unrelated AI-security paper" (now 11 papers, two domains); comments about the removed paper reworded.
2. README: unit test count (1,150 -> 1,494 + 58 integration), database size (17 MB -> 38 MB for both schemas), corpus description, Prompt Guard text.
3. `.env.example` lacked 13 variables the code reads (bucket, subscription, schema, MLflow, Tesseract, local figures, parallel switch): added.
4. Prompt Guard block level set to the model's own 0.5 as requested (code, tests, README, report, update log, interview notes).

## Verified clean
- Secrets: no key, token or password in any pushable file (3 benign matches: a local docker-compose default and two test constants). `.env` is ignored.
- Code: everything compiles; no TODO/FIXME, no bare `except:`, no mutable default arguments; every SQL value is a parameter (15 f-string SQL statements reviewed: all interpolate schema, table or column constants only).
- Tests: 1,494 unit, 58 integration, 3 live; the layout test and the Docker early-layer test guard the package boundaries and the image build.
- Dependencies: `pip check` finds no conflicts; the worker's versions equal the app's; Dependabot is configured for pip, actions and Docker.
- Workflows: all five parse; permissions are `contents: read`; deploys use Workload Identity (no key); each deploy job has its own concurrency group.
- Cloud: bucket public access prevention enforced, uniform access on, 60-day soft delete; secrets list contains no Neo4j entries; the worker, trigger and deployer accounts hold narrow roles; Cloud Run scales 0-5, 80 requests per instance, 300 s.
- Data (`rag_v2`): 11 active documents; no chunk without a parent or parent without chunks; no NULL embeddings (768 and 512 dimensions); no duplicate ids; every chunk belongs to an active document; every table and image has a parent link; 182 image rows = 182 files in the bucket; vector indexes exist; 1 of 901 connections in use; database 38 MB.
